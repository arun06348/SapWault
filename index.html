Connect to GitHub

Links are saved to links.json in your repository so they show up for everyone, on every device. To add or delete links you need a token. Viewing needs nothing.
  1. Open GitHub → Fine-grained token.
  2. Repository access: Only select repositories → pick this repo.
  3. Permissions → Repository → Contents: Read and write. Generate and paste below.
The token stays only in this browser. Never put it inside the HTML file.
